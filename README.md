# boostregex

Boost lightweight regex statistics from stdin samples.

**Site:** https://theworker02.github.io/boostregex/

## Install / run

```bash
git clone https://github.com/theworker02/boostregex.git
cd boostregex
node src/cli.js
node --test
```
